# Sistema de Revisión de Fotos - Venier

Sistema para revisión de fotos de ejecuciones de promotores.

## Funcionalidades
- 📸 Revisión de fotos con zoom
- ✅ Asignación de status (Objeción/Inválida/Fraude)
- 📊 Estadísticas en tiempo real
- 📥 Exportación a Excel
- 🔒 Cierre de mes

## Tecnologías
- Python + Flask
- SQLite
- HTML + CSS + JavaScript

## Instalación
1. Clonar repositorio
2. `pip install -r requirements.txt`
3. `python app.py`
